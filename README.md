# Neurodesk Literature Records

Companion literature library for the Neurodesk thesis poster by Guanyu Yao.

[Workflow code and installation](https://github.com/Bran-Y/neurodesk/tree/main) | [Download bibliography](bibliography.csv)

## How to use this library

- Browse the paper titles and DOI links below; open the linked JSON files for extracted numerical records and source locations.
- Numerical evidence includes reference distributions, group effects and reported method statistics. These are not interchangeable.
- A library entry does not imply a compatible patient comparison, human verification, or a validated diagnostic model. Original review and compatibility fields are retained.
- This branch contains literature metadata and published aggregate statistics only. No patient scans, individual patient measurements, QC records, or full-text PDFs are included.
- Snapshot: 15 October 2026. Bibliography and AD records from workflow main commit `7fe61dad62ae9f721d204698379ffd053d7c6f9b`; PD aggregate records from the existing local workflow literature library. This independent branch is not automatically synchronized with main.
